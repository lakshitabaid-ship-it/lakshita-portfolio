# Submission Guide — Lakshita Baid Portfolio

## 1. Before you submit

1. Preview `index.html` locally. Check every section and the mobile view (browser DevTools → device toolbar).
2. Fill in placeholders you have real information for (see `README.md → How to replace placeholders`). Leaving a placeholder is fine; inventing information is not.
3. Confirm the name reads **Lakshita Baid** everywhere.

## 2. Publish on GitHub Pages

1. Create an account at <https://github.com> if needed.
2. **New repository** → name `lakshita-baid-portfolio` (or `<username>.github.io`) → **Public**.
3. Upload `index.html`, `style.css`, `script.js` and the `assets` folder (*Add file → Upload files*), keeping the folder structure. Or use Git:
   `git init`, `git add .`, `git commit -m "Initial portfolio"`, `git branch -M main`, `git remote add origin <repo-url>`, `git push -u origin main`.
4. Commit.
5. **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.
6. Wait 1–3 minutes and copy the live URL from the top of the Pages settings (format `https://<username>.github.io/<repo-name>/`).
7. Copy the repository URL from the repo's home page.

## 3. Verification checklist

- [ ] Live page loads and shows styling
- [ ] No 404 errors in the DevTools console
- [ ] Navigation links scroll to the right sections
- [ ] Mobile menu opens, closes with Escape and traps focus
- [ ] Placeholders display (no broken images)
- [ ] File names match case exactly

## 4. Make the PDF

1. Open `SUBMISSION_PDF_DRAFT.md`, copy the text into Word or Google Docs.
2. Replace `[YOUR ROLL NUMBER]`, `[PASTE LIVE GITHUB PAGES URL]` and `[PASTE REPOSITORY URL]`.
3. File → Download / Save as PDF. Confirm it is 2 pages or fewer.
4. Rename the file `RollNo_WD_MTProject.pdf` (using your real roll number).

## 5. Updating later

Edit files on GitHub (pencil icon) or push a new commit. Hard-refresh the live page if you see an old version.
